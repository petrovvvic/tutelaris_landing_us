# tutelaris – englische Fassung (tutelarisapp.com)

Diese Seiten werden **erzeugt**, nicht von Hand gepflegt. Quelle ist das deutsche
Repository `tutelaris-landing`, Branch `landing-new`.

## Neu erzeugen

Im deutschen Repository:

```bash
python3 tools-baue-en.py          # erzeugt die englischen Seiten unter en/
python3 tools-baue-en-site.py /pfad/zu/diesem/repo
```

Danach hier committen und pushen. Änderungen direkt in diesen Dateien gehen beim
nächsten Durchlauf verloren.
